# Knollwood Village Civic Club website

Static site for knollwoodvillage.org, built with Astro. Content is Markdown and JSON so non-developers (and Claude) can edit it on GitHub.

## Commands
- `npm install` then `npm run dev` for a local preview at http://localhost:4321
- `npm run build` writes the site to `dist/`. Run it before every commit that touches code.
- `BASE_PATH=/Knollwood-Village/ npm run build` is what the GitHub Pages preview uses.

## Where things live
- `src/data/site.json`: dues amount and year, role emails, patrol dispatch, phone list, nav, Mailchimp and PayPal IDs. Change the dues amount here and it updates everywhere.
- `src/data/officers.json`: officers, board, committees (Contact page).
- `src/data/newsletters.json`: newsletter archive. Add an entry and drop the PDF in `public/docs/newsletters/` as `KVV-YYYY-QN.pdf`.
- `src/content/news/*.md`: news posts and events. Frontmatter: `title`, `date`, optional `description`, `eventDate`, `eventEnd`, `location`, `image`. Posts with a future `eventDate` show as "Coming up" on the home page.
- `src/content/pages/*.md`: simple content pages (about, ACC FAQs, advertise, new-residents, standard ACC request). File path = URL.
- `src/pages/*.astro`: pages with custom layout (home, dues, security, contact, build, deeds, map, dues map, newsletters, documents).
- `public/docs/`: PDFs, organized by `newsletters/`, `deeds/`, `acc/`, `club/`, `archive/`. Keep every file under 20 MB (Cloudflare Pages limit is 25 MB). Compress with `gs -sDEVICE=pdfwrite -dPDFSETTINGS=/ebook`.
- `public/data/parcels.geojson`: lot polygons from HCAD, trimmed to address, section, lot, account. No owner data.
- `public/data/dues/YYYY.json`: per-address dues status for the map. Generated by `scripts/export-dues.py` from the treasurer's master spreadsheet. Status only, no names or amounts.
- `public/_redirects`: Cloudflare Pages redirects from old WordPress URLs. `src/data/page-redirects.json` does the same for page URLs on any host.
- `src/scripts/`: Leaflet map code (`map.ts` neighborhood and deeds map, `dues-map.ts`).

## Conventions
- Internal links in `.astro` files go through `url('/path/')` from `src/lib/url.ts` so the base path works. In Markdown, plain `/path/` links are fine (a rehype plugin adds the base).
- Never commit resident names, emails, phone numbers, or payment amounts. The dues data files contain status flags only.
- Dates in news frontmatter are ISO. Event times include the Central offset, e.g. `2026-10-06T18:00:00-05:00`.
- Keep the voice plain and warm. Short sentences. No HOA-speak: KVCC is a voluntary civic club.

## Updating the dues map
1. Treasurer updates the `PNP.Master` tab of `KVCC.Master.YYYY.xlsx`.
2. Run `python3 scripts/export-dues.py path/to/KVCC.Master.YYYY.xlsx YYYY` (needs `pip install openpyxl`).
3. Commit the changed `public/data/dues/YYYY.json`.

## Deploy
Pushes to `main` deploy automatically (GitHub Actions to GitHub Pages for the preview; Cloudflare Pages once connected). See `docs/PLAN.md` for the cutover checklist.
