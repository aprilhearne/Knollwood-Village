# Knollwood Village Civic Club website

Source for the rebuilt knollwoodvillage.org: a static site managed through GitHub, with an
interactive neighborhood map and a board-only dues-status map.

- [docs/LOCAL-SESSION.md](docs/LOCAL-SESSION.md): how to kick off Phase 1 in a local Claude Code session
