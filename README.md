# Knollwood Village Civic Club website

Source for [knollwoodvillage.org](https://knollwoodvillage.org): a static site built with Astro and managed through GitHub.

- **Preview:** https://aprilhearne.github.io/Knollwood-Village/ (rebuilt automatically on every push to `main`)
- **How to edit:** see [CLAUDE.md](CLAUDE.md) for where every kind of content lives.
- **Plan and cutover checklist:** [docs/PLAN.md](docs/PLAN.md)

## Local development

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # writes dist/
```
